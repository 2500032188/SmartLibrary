SmartLibrary Advanced Full Project
==================================
Eclipse Java project, package smartlibrary, Java 8 compatible.

Copy/import src/smartlibrary/*.java into the project's src/smartlibrary package.
Keep dataset/SmartLibrary_Dataset.csv at the PROJECT ROOT (same level as src).
Run smartlibrary.SmartLibrary as Java Application.

Menu covers dataset viewing, naive/KMP/Z/Rabin-Karp search, Levenshtein/Damerau edit distance,
suffix array + Kasai LCP, Needleman-Wunsch/Smith-Waterman scoring, matrix-chain, optimal BST,
bitmask TSP, Edmonds-Karp max flow, vertex-cover 2-approximation, Miller-Rabin and reservoir sampling.

Limitations (important for honest review): this is a classroom demonstration and does not implement every syllabus item.
Aho-Corasick, true linear-time SA-IS, suffix tree/automaton, Dinic/min-cost flow, full scheduling reductions,
tree DP/SOS DP, and parallel scan/reduce are not implemented in this starter. Suffix array uses an educational
insertion-sort build. The engine uses arrays for algorithmic data structures; Scanner is only for console input.
